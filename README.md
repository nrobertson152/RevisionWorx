# RevisionWorx
A FOSS PDM software that integrates seamlessly with OpenSchematix

## Engineering development

Development follows a three-role workflow: one **Coder** (Claude or ChatGPT), one independent **ChatGPT Reviewer**, and an **Engineering Coordinator**. The Director retains final merge and release authority. See [AGENTS.md](AGENTS.md), [the coordination playbook](docs/agents/README.md), and [the coordinator report standard](docs/agents/COORDINATOR_REPORT_STANDARD.md).
