# RevisionWorx branding

- `revisionworx-logo-original.png` — the official logo exactly as the Director supplied it (2026-11-05): the white
  R on the blue rounded square, presented on a dark background.
- `revisionworx-icon.png` — the blue rounded square alone at full resolution, transparent outside it.

The application icons in `revisionworx/gui/resources/` (PNG 16-512 px and the Windows `.ico`) are derived from the
original by `packaging/make_icons.py`. Nothing is redrawn. Use only this artwork for RevisionWorx
(`docs/REVISIONWORX_BRANDING_DIRECTIVE.md`).
