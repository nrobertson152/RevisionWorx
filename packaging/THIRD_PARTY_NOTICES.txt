RevisionWorx standalone build - third-party components
=======================================================

RevisionWorx itself is free software under the GNU General Public License, version 3 or (at your
option) any later version. See LICENSE in this folder. Source code:
https://github.com/nrobertson152/RevisionWorx

This folder also contains, unmodified and as separate shared libraries:

* Python (CPython) runtime and standard library
  Python Software Foundation License Version 2. https://docs.python.org/3/license.html
  Source: https://www.python.org/downloads/source/

* Qt 6 and Qt for Python (PySide6 / Shiboken6), desktop window only
  GNU Lesser General Public License, version 3 (LGPL-3.0). The license texts shipped with PySide6
  are copied into the "licenses" folder when the build includes them.
  Qt source: https://download.qt.io/official_releases/qt/
  Qt for Python source: https://code.qt.io/cgit/pyside/pyside-setup.git/
  These libraries are dynamically loaded from this folder; you may replace them with
  compatible versions you build yourself.

* PyInstaller bootloader (used to start the program)
  GPL-2.0 with the PyInstaller bootloader exception. https://pyinstaller.org/en/stable/license.html

The command line (revisionworx) uses only Python and its standard library.
